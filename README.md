# Workshop RPA + Make

Presentación web de CDA sobre RPA y automatización con Make.

## Contenido y mantenimiento

La presentación está en [`index.html`](index.html). Es un sitio estático: no requiere servidor de aplicaciones, instalación de dependencias ni base de datos. Revisar los enlaces, la navegación y la visualización en escritorio y móvil al editarlo.

## Vista local

Desde la raíz del repositorio:

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

Abrir `http://127.0.0.1:8000/`. La vista local no publica cambios en GitHub Pages.

## Publicación

GitHub Pages publica el contenido configurado en Settings → Pages. Comprobar el resultado de la publicación y la URL indicada allí después de actualizar la rama de origen. Conservar la historia y no agregar credenciales, datos personales ni documentación interna a este repositorio público.
